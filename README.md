# s-ui

给不写前端的人用的 AI 页面设计工作台。在自己电脑上启动，浏览器里选一个项目文件夹，左边和 AI 对话，中间实时显示页面；在页面上画个圈、说一句话，AI 就去改真实的源代码，页面随即刷新。

> 当前是原型，只验证从对话、画圈到改代码的整条链路。

## 准备

- Node.js 24 或更新版本
- 已在本机登录过 [pi](https://www.npmjs.com/package/@earendil-works/pi-coding-agent)（s-ui 直接复用 `~/.pi/agent/auth.json` 里的登录，例如 `pi` 里 `/login` 登录 OpenAI Codex 订阅，或配置任一厂商的 API key）
- 首次使用安装依赖和截图用的浏览器：

```bash
npm install
npx playwright install chromium
```

## 启动

```bash
npm run dev
```

后台启动后会自动打开浏览器（地址 `http://127.0.0.1:5180/`）。可选参数：`npm run dev -- --port 6000 --no-open`。按 Ctrl+C 退出，s-ui 启动的所有页面服务会一起关掉。

## 使用

1. 顶栏输入项目文件夹路径后点“打开”，或点“试试示例项目”。文件夹不存在会自动新建。
2. 已有前端项目（`package.json` 里有 `dev` 脚本）：没装依赖时会先自动安装，然后启动页面并显示在中间。
3. 空文件夹：在左边对 AI 说“做一个咖啡店的落地页”之类的话，AI 会建一个最小的 Vite 项目，完成后页面自动出现。
4. 想改页面某处：点右上角“画圈修改”，在页面上圈出区域，在弹出的输入框里写一句话发送。AI 会收到带红圈的截图和圈内元素在源码里的位置，改完后页面自动刷新。
5. 模型在顶栏选择，在本次运行中首次打开该文件夹时生效；默认 `openai-codex/gpt-5.6-luna`。右上角可切换中英文，默认跟随浏览器语言。

## 已知限制

- 画圈截图由后台按预览当前的地址和整页滚动位置重新打开页面生成；页面内的临时状态（展开的菜单、弹窗、输入内容）和局部滚动区域的位置不会还原，这种情况下截图和圈内元素可能与你看到的不一致。
- 圈内元素的源码位置按 id、文字和 class 在源码里搜索得出，可能不准或找不到。
- 对话只保存在内存里，s-ui 退出后不保留。
- Claude 订阅登录（OAuth）不可用；使用 Anthropic 模型需要配置 API key。
- 目前只在 macOS 上验证过。
