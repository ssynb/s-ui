# s-ui

给不写前端的人用的 AI 页面设计工作台。在自己电脑上启动，浏览器里选一个项目文件夹，左边和 AI 对话，中间实时显示页面；在页面上画个圈、说一句话，AI 就去改真实的源代码，页面随即刷新。

> 当前是原型，只验证从对话、画圈到改代码的整条链路。

## 准备

- Node.js 24 或更新版本
- 已在本机登录过 [pi](https://www.npmjs.com/package/@earendil-works/pi-coding-agent)（s-ui 直接复用 `~/.pi/agent/auth.json` 里的登录，例如 `pi` 里 `/login` 登录 OpenAI Codex 订阅，或配置任一厂商的 API key）
- 首次使用安装依赖和截图用的浏览器：

```bash
npm install
npx playwright install chromium
```

## 启动

```bash
npm run dev
```

后台启动后会自动打开浏览器（地址 `http://127.0.0.1:5180/`）。可选参数：`npm run dev -- --port 6000 --no-open`。按 Ctrl+C 退出，s-ui 启动的所有页面服务会一起关掉。

## 使用

1. **选项目**：启动后是欢迎页，左边是“打开文件夹…”“新建项目…”“打开示例项目”（示例第一次打开时复制到 `~/.s-ui/examples/`，之后改的都是这份副本），右边是最近打开过的项目，点一下就打开。打开项目后，左上角的项目名 ▾ 可以随时切换到其他最近项目，或再打开、新建。
   - “打开文件夹…”会弹出文件夹选择框：左边有主目录、桌面、文稿快捷入口，右边的目录树可以逐层展开，也可以在顶部路径栏直接输入或粘贴路径后回车跳转。含 `package.json` 的文件夹会标为“前端项目”。
   - 本层没有 `dev` 脚本时，只检查直接子目录（跳过隐藏目录、依赖目录和符号链接）。找到多个项目时先选择，再启动；只有一个时直接打开它。
   - “新建项目…”填一个名字，选好存放位置，s-ui 会在那里建一个空文件夹并打开。
   - 最近项目记录在 `~/.s-ui/config.json`；设置环境变量 `S_UI_HOME` 可把 s-ui 自己的目录换到别处。
2. **已有前端项目**（`package.json` 里有 `dev` 脚本）：没装依赖时会先自动安装，然后启动页面并显示在右边的预览区。底部状态栏显示页面服务的状态和地址。
   - Next.js App Router 项目会发现 `app/` 或 `src/app/` 下的固定地址页面。多个页面时先看缩略图，点开滚动查看整页，再点“选这个页面”进入该路由的实时预览；地址栏的“切换页面”可重新选择。只有一个页面时直接进入。
   - 页面截图来自当前项目的真实预览响应，不发送给 AI、不写进项目；截图失败会标明原因，仍可选择该路由。画圈与打磨始终读取实际预览页面，不读取缩略图。
   - 文件夹有内容但没有启动入口时显示“未找到启动入口”，可以重新打开文件夹；不会进入空项目起步流程。
3. **空项目**：预览区显示“先选一个参考定基调”。可以先写一句想做什么（如“精品咖啡店官网”）点“找同类”，AI 按这句话找同类产品的真实页面；也可以直接在“精选”里挑。点卡片看大图，勾选要参考的方面，点“照这个做”，AI 会照参考的版式、配色和字体搭出页面，并把字体、颜色、圆角、阴影、间距集中写进 `src/design-tokens.css`，之后可以直接打磨。也可以不选参考，直接在左边对 AI 说“做一个咖啡店的落地页”。页面跑起来后预览自动出现。
4. **工具窗**：最左侧的图标条切换左栏的工具窗：对话（默认）、打磨、参考页面。切换时对话内容和输入框里的草稿都会保留。
5. **参考页面**：找一个好看的真实页面，让 AI 照着改。
   - “同类产品”页点“找同类产品”：AI 读项目，判断它是什么产品、什么页面，列出同类产品的对应页面；s-ui 逐个打开验证并截首屏，打不开、错误页、需要登录的会被丢弃，可展开看原因。整个过程约一两分钟，结果边验证边出现。
   - “精选”页按类型（SaaS 首页、定价页、AI 对话产品、设置页、仪表盘、作品集、电商详情）列出优质页面，点到哪一类才截那一类；没打开的页面，再点一次该类会重试。
   - 顶部输入框可以粘贴任意网址加入参考。
   - 点卡片看大图，可往下滚动看整页；勾选要参考的方面（版式布局、配色、字体层级、组件风格），点“参考这个”，截图和要求一起发给 AI，并切回对话。预览里有圈选时，只改圈中的部分。
   - 同一项目的找同类结果在参考页面、空项目起步页和打磨里共用，查一次即可。
   - 截图只存在本机 `~/.s-ui/reference-shots`（同一网址 7 天内复用），只发给你选的模型，不会写进项目。
6. **对话**：长用户消息默认显示开头几行，点“展开全部”查看完整要求，图片仍完整显示。AI 的回复按 Markdown 显示；它读写文件、执行命令等操作折叠成一行，点开可以看每一步。AI 处理时顶栏会显示进度和停止按钮。
   - 对话按项目自动保存（在 `~/.s-ui/sessions/` 下），切换项目再切回、退出后重开，对话内容（包括圈注截图）都会恢复，AI 也记得之前聊过什么。
   - 对话工具窗标题栏右侧：铅笔图标开一个新对话，时钟图标列出这个项目最近的对话，点一下切回去。旧对话不会被删除。
7. **画圈修改**：点预览区地址栏右边的“画圈修改”，预览区出现蓝色边框和提示，在页面上圈出区域，在弹出的输入框里写一句话发送。AI 会收到带红圈的截图和圈内元素在源码里的位置，改完后页面自动刷新。按 Esc 或点“退出画圈”随时退出。
8. **模型与语言**：模型在顶栏右侧随时切换，从下一条消息起生效，并记在这次对话里（切回这个对话时沿用）；底部状态栏显示当前模型。默认 `openai-codex/gpt-5.6-luna`。界面中英文可在顶栏切换，默认跟随浏览器语言；浅色、深色跟随系统设置。
9. **打磨**：只放和当前页面有关的东西，点一下右边预览立刻变，满意再保存。
   - 第一次用时顶部有一张“先整理一次设计设置”卡片：AI 把代码里散落的字体、颜色、圆角、阴影、间距收拢进 `src/design-tokens.css`，页面外观不变（整理前后截图比对，不一致会撤销）。要等页面在预览里跑起来、且对话里的 AI 空闲时才能整理；整理进行中面板顶部显示进度，对话输入框禁用并提示“正在整理设计设置…”，已有草稿保留，完成后恢复输入。外观检查同时比较 1280×800 桌面和 390×844 窄屏下的整页截图。
   - 字体（中英搭配，含思源黑体/宋体、霞鹜文楷等免费网页字体）、配色（色板或自选主色，主色上的文字色按对比度自动选）、形状与密度（圆角、间距、阴影）点一下即在预览里生效，再点一次或点“原样”回退；底部“保存”直接写进设计变量文件，不经 AI。换配色后若还有元素保持原来的主色（代码里写死的颜色），配色栏会列出它们，可一键让 AI 改用设计设置。
   - “页面里的组件”列出页面上实际有的按钮、链接、输入框、卡片等及数量，每类可试 3–4 种做法；“动效”可在这些组件上试按压、悬停、焦点环、出现、加载等效果并调参数。满意后点“应用”，把做法、选择器、现在的样式和要求整理成一条需求交给 AI 改代码。
   - 底部显示未保存的改动数；“全部还原”撤掉预览里所有试用效果。切换工具窗或项目再回来，未保存的改动还在。

## 已知限制

- 选页发现只支持 Next.js App Router 默认的 `page.js/jsx/ts/tsx` 文件；route groups 不占 URL 段，动态参数、私有目录、并行与拦截路由不列为独立页面。暂不解析自定义页面扩展名、`basePath`、rewrites 或其他路由框架；其他项目仍使用 dev server 默认地址。页面列表在启动时发现，新增路由需重启工作台。截图不会跟随页面跳转，重定向页面可能显示截图不可用，但仍可进入实时预览。

- 圈内元素直接从你此刻看到的预览页面里取；截图由后台把这一刻的页面快照（含弹窗、输入内容、各处滚动位置）重新渲染得到。Shadow DOM 里的内容、跨域图片绘制的画布和 WebGL 画面在截图里可能显示为空白。
- 圈内元素的源码位置按 id、文字和 class 在源码里搜索得出，可能不准或找不到。
- 对话记录里的图片（圈注截图、附图）随对话保存在本机，长期使用后 `~/.s-ui/sessions/` 会变大，目前没有清理入口。
- 找同类产品没有接搜索引擎，候选网址来自模型自己的知识，可能过时，所以要逐个打开验证；被丢弃的多了时结果会少于 6 个。截图前会尝试关掉 Cookie 同意条和促销弹窗，个别网站的弹窗、地区跳转或反爬拦截仍可能出现在截图里或导致被丢弃。
- Claude 订阅登录（OAuth）不可用；使用 Anthropic 模型需要配置 API key。
- 目前只在 macOS 上实测过。Windows 已按平台做了处理但未实测：文件夹选择框列出存在的盘符；包管理器经 `cmd.exe` 启动；停止页面服务用 `taskkill /T /F` 结束整个进程树。Linux 未实测。
